# Generating Functions Lab

Generating functions taught as a calculus for discrete structures. Every lesson runs the same
cycle, **problem → discrete object → encode → manipulate → read coefficient → answer → verify**, and
keeps the objects, the coefficient strip, the series tape, the closed form and the answer in step:
selecting a coefficient anywhere selects it everywhere. Thirty-four levels go from encoding
1, 1, 1, … to roots-of-unity filters, the DFT as evaluation at roots of unity, the inverse DFT as
coefficient extraction and the cyclic convolution theorem, then partitions, singularity analysis
and two optional lessons (saddle point, multivariate diagonals). Published at
`https://teoyujie.org/visuals/generating-functions` (the spec's `generating-functions.html` and its
fragments, such as `#coin-change` or `#dft`, map onto this URL's hash).

`index.html` is one self-contained file: no network requests, no external scripts or fonts and no
TeX library (maths is Unicode and HTML from a small TeX-subset renderer). It works from `file://`
and in an iframe, follows the light/dark preference (with a manual toggle) and reduced motion, and
keeps a full text version in `<noscript>`.

| File | Role |
| --- | --- |
| `engine.js` | Pure mathematical core, no DOM (`self.GF`, or `require`). Exact integer series (BigInt), rational series, the cyclotomic ring ℤ[ζ_N] for exact values at roots of unity (exact DFT, inverse DFT, filters, convolution theorem), brute-force enumerators for every counting example, complex floats for pictures, Γ and the asymptotic estimates, and the TeX-subset → HTML renderer. |
| `lessons.js` | The curriculum (`self.GFLab`): 34 lessons, each with its problem, generating function, coefficients, independent check, states (stage, title, TeX, text, narration), hints and links; the 22-problem ladder; comparisons; the verification engine; deep links; search; and the beamdswitch reports built from the same states. |
| `ui.js` | The page: Explore, Guided, Problems, Compare and Transform modes, the concept map, one visual per lesson, the Fourier lab, the sandbox, the command palette (⌘K / Ctrl-K), the in-page presentation, Markdown export and the read-only WebMCP tools. |
| `beamdswitch.js` | The site's standard beamdswitch report template, an unchanged copy of yujieteo/site's `templates/beamdswitch.js`. |

| `raw.json` | Levels, fragments, techniques, problems, conventions and the spec corrections (published as `data.json`); generated by `node raw.mjs > raw.json`. |

## Exactness and verification

Counting is exact throughout: integer coefficients are BigInt, EGF, PGF and Lagrange coefficients are
rationals, and values at roots of unity are elements of ℤ[ζ_N] reduced modulo the cyclotomic
polynomial, so `IDFT(DFT(a)) = a` and the convolution theorem are checked exactly. Exact strings are
shown for N = 2, 3, 4, 6, 8 (for example A(i) = −2 − 2i). Floating point is used only for phasor
pictures, plots and the asymptotic comparisons, which state their tolerance (for example
|Cₙ/(4ⁿ/(√π n^{3/2})) − 1| ≤ 1.2/n). Every lesson compares its coefficient with an independent
count: brute-force enumeration (coin solutions, compositions, strings, trees, permutations, set
partitions, partitions, dice outcomes, parent maps for Cayley trees), a dynamic-programming
recurrence, or an exact transform.

## Conventions

- OGF A(x) = Σ aₙxⁿ; EGF Σ aₙxⁿ/n! (strips show the counts aₙ); PGF G(z) = E[z^X].
- Fibonacci F₀ = 0, F₁ = 1. The strip 1, 1, 2, 3, 5, 8 of the shift lesson is aₙ = Fₙ₊₁.
- DFT: Âₖ = A(ωᵏ) with ω = e^{+2πi/N}, as in the spec's N = 4 example (ω = i). numpy's `fft` uses
  e^{−2πi/N}, so its entry k is entry N − k here.

## Tests

This repository, yujieteo/generating-functions, is where the lab and its tests develop; CI runs them on
every push and pull request. yujieteo/site's `visuals/generating-functions/` is a port of the page
files (this repository minus `tests/` and `.github/`) and runs none of these tests.

`tests/generating-functions.test.mjs` (the mathematics against independent enumerations, deep
links, search, TeX), `tests/generating-functions-beamdswitch.test.mjs` (every lesson, problem and
the full deck parsed with beamdswitch's own parser; reveal order follows the lesson states),
`tests/generating-functions-page.test.mjs` (every route boots against a stand-in DOM, WebMCP tools,
no-network and no-JavaScript checks) and `tests/test_generating_functions.py` (build
reproducibility and the self-test under Node). `tests/fixtures/beamdswitch/` holds read-only copies
of beamdswitch's deck parsers and the site's shared template and report outline.

```sh
node --test 'tests/*.test.{mjs,cjs}'
python3 -m unittest discover -s tests -p 'test_*.py'
```
