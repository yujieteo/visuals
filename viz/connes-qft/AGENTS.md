# Connes QFT laboratory

`index.html` is generated. Edit `template.html`, `src/` or `raw.json`, then run `python3 build.py`. Use `python3 build.py --check` to check its bytes.

The engine modules in `src/` use no DOM, storage, clock, randomness or network. Keep the three lenses distinct. Keep finite, lattice and toy models labelled. Use natural units and the existing charge and metric conventions.

This folder is the source of truth in yujieteo/visuals. Node tests live in `tests/`. Browser checks live in `e2e/`. Follow the repository [SKILLS.md](../../SKILLS.md).
