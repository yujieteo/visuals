Universal Data Workbench

Import CSV or Parquet tables and see what each column holds: its type, its role, what is missing, what does not read and what is unusual. Then every valid chart of a documented grammar is drawn for each table, tested where a test applies, and ranked in two lists, unusual patterns and statistically supported patterns, each with distinct highlights explained. You need no question and no chart to start.

      How the workbench reads a table

      • A CSV is imported as text: every value stays exactly as written. The workbench reads a column as a type only for analysis, so the table never changes.
      • A column reads as a type when at least 95% of the values present fit it: yes or no, whole number, decimal, ISO date, ISO date-time, time, or one other date layout. Otherwise it is categorical (at most 1,000 levels and fewer than half distinct) or text. The share is shown as the uncertainty.
      • Empty values are missing. Markers such as NA, N/A or null are counted apart and become missing only when you approve it. So do stand-ins such as -999.
      • Dates whose day and month order is ambiguous, or that mix two layouts, stay text until you choose a layout.
      • An identifier is never a measure: a name such as id, code or zip, leading zeros, UUIDs, or nearly unique values that run without gaps make one.
      • Unusual values have a robust z above 3.5, where z = (x − median) / (1.4826 × the median absolute deviation). They stay in the data, apart from suspected errors.
      • Every result uses all rows of the table. A table imported as a seeded sample says so everywhere.
      • Charts follow grammar v1: each column is a measure (Q, at least 13 distinct numbers), a category (C, at most 1,000 levels), a time (T) or a label (L), or is excluded with its reason. Every single-field and two-field chart of those classes, and every timeline, is a candidate. Bins, scales, levels and time periods follow fixed rules; a scatter plot of more than 50,000 points draws a seeded sample and says so.
      • Figures are drawn on white paper, as they will be exported, in both page themes.
      • Each table is one family of hypotheses, listed before any test: each pair of measures a monotone association (Spearman), each category and measure a group difference (Welch's t or ANOVA), each pair of categories an association (chi-square, Fisher or a permutation test), each time and measure a trend (Mann–Kendall) and a level shift (CUSUM). A test runs only when its checks pass; otherwise the reason is listed. Raw p-values are adjusted by Benjamini–Yekutieli over the tests that ran; an adjusted p-value at or below 0.05 is exploratory evidence, not proof. Every rule: test catalogue v1.
      • Without study details, tests of independent rows run tagged "independence assumed, not confirmed", and are refused where the data contradicts independence: an identifier that repeats in 10% or more of its values, or a lag-1 autocorrelation above 0.3 (p below 0.01) in time order.
      • Charts are ranked by unusualness: usefulness (how large the effect is against a large one) × the share of complete rows − penalties for low density, label collisions, many categories, overplotting, small groups, missing values and samples. A chart with fewer than 5 complete rows or a field with one value is excluded. Values flagged as stand-ins for no value are left out of the statistics and counted.
