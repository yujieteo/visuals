Divisors, Linear Systems & Riemann–Roch

A computational laboratory for algebraic curves: allowed poles → rational functions → L(D) → ℓ(D) → Riemann–Roch → the map φD to projective space.

Choose a curve, place a divisor, and this page finds the rational functions whose poles the divisor allows, counts them, checks Riemann–Roch and draws the map they define. The laboratory needs JavaScript; the core computations are below.

The question

L(D) = { f : div(f) + D ≥ 0 } ∪ {0}, ℓ(D) = dim L(D)

Given specified allowed poles, how many independent rational functions exist — and what map to projective space do they define?

Riemann–Roch

ℓ(D) − ℓ(K − D) = deg D + 1 − g, deg K = 2g − 2

When deg D > 2g − 2 the obstruction ℓ(K − D) vanishes and ℓ(D) = deg D + 1 − g: the divisor is nonspecial.

Worked computations

  • P¹: L(d∞) = ⟨1, x, …, xd⟩, so ℓ(d∞) = d + 1; the map is the Veronese embedding P¹ → Pd (d = 2: the conic XZ = Y²; d = 3: the twisted cubic).
  • Elliptic curve E: y² = x³ + ax + b, genus 1, K ∼ 0, so ℓ(D) = deg D when deg D > 0. L(2O) = ⟨1, x⟩ gives the double cover E → P¹ branched at the three roots and ∞; L(3O) = ⟨1, x, y⟩ (pole orders 0, 2, 3) embeds E in P² as y²z = x³ + axz² + bz³.
  • P ↦ [P − O] identifies E with Pic⁰(E); the chord through P and Q meets E again at R, and P + Q + R ∼ 3O gives the group law.
  • Riemann–Hurwitz for a double cover of P¹ with 2g + 2 branch points: 2g − 2 = 2(−2) + (2g + 2); six branch points give genus 2, whose canonical map φK : C → P¹ is the 2 : 1 hyperelliptic cover.
  • Smooth plane curves of degree d: g = (d − 1)(d − 2)/2 and, by adjunction, K = (d − 3)H. A smooth plane quartic has K = H: its plane embedding is its canonical embedding, genus 3.

    Linear equivalence and Pic(C)

    D ∼ D′ when D − D′ = div(f). Adding a principal divisor moves zeros and poles while the curve stays fixed; Pic(C) = Div(C)/Prin(C) splits by degree into Picd(C).

    On P¹: every degree-d divisor is one class

    Pic(P¹) ≅ ℤ

    Each column is a class: the divisors in it differ by a principal divisor, and the class is remembered only by its degree.

    The Riemann–Roch balance

    ℓ(D) − ℓ(K − D) = deg D + 1 − g

    Sections of D, minus the obstruction from K − D, equal degree plus topology. Raise the degree to add sections; raise the genus to add constraints. Abstract curve, so where the curve itself decides the answer the bar shows a range.

      Computation mode
      
      
      Symbolic bases for P¹ (any divisor written as 2[0] + [1] - [inf]), Weierstrass elliptic curves and hyperelliptic curves y^2 = f(x) (divisors n∞, nO or K). Other requests are answered by Riemann–Roch, not by a fabricated basis.
      
      
      
        
        
        
      task: compute L(D)
      
        
      
        
      
      
      Pole-order semigroup and Weierstrass gaps
      
      
      H(P) = {n ≥ 0 : some f has poles only at P, of order exactly n}. The missing values are the gaps; there are exactly g of them.
      
      
      
      
      
    
      

    
      
      
      The function-field view: valuations
      
      
      Points of C are the discrete valuations vP of k(C); a divisor is a finite sum of valuations, and f ↦ (vP(f))P. Membership f ∈ L(D) is the system vP(f) ≥ −nP.
      
      
      Toy example on P¹: functions xa(x − 1)b, with v₀ = a, v₁ = b, v∞ = −a − b, and D = n₀[0] + n₁[1] + n∞[∞].
