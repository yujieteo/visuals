Entropy Methods in Combinatorics

Entropy as a counting technology

To count a finite family F, choose an object X uniformly at random. Then H(X)=log2|F|: the count is an information budget. Encode X by coordinates, bound the information they carry with entropy inequalities, and exponentiate.

  1. COMBINATORIAL FAMILY
  2. sample uniformly → RANDOM OBJECT X
  3. choose coordinates → (X₁,…,Xₙ)
  4. information inequality → ENTROPY BOUND
  5. H(X) = log |𝓕| → COUNTING BOUND

Fundamental entropy inequalities

  • Maximum entropy: H(X)≤log|supp(X)|
  • Chain rule: H(X,Y)=H(X)+H(Y ∣ X)
  • Conditioning: H(X ∣ Y)≤H(X)
  • Subadditivity: H(X1,…,Xn)≤∑iH(Xi)
  • Mutual information: I(X;Y)≥0
  • Gibbs: D(P‖Q)≥0
  • Data processing: H(f(X))≤H(X)
  • Shearer: rH(X)≤∑jH(XAj)
  • Fractional Shearer: H(X)≤∑AαAH(XA)
  • Loomis–Whitney: |S|d−1≤∏i|πi(S)|
  • Bregman: per(A)≤∏i(di!)1/di

Entropy proof of the binomial bound

Bound (nk).

(nk)≤2nh(k/n).

  1. Encode S by its indicators: H(X1,…,Xn)=log(nk).

    uniform

  2. H(X)≤∑iH(Xi).

    subadditivity

  3. By symmetry Pr[Xi=1]=k/n, so H(Xi)=h(k/n).

    symmetry

  4. log(nk)≤nh(k/n); exponentiate.

    exponentiate
Clever move.

Encode a random k-subset using n dependent Bernoulli coordinates, then deliberately forget their dependence.

  • (103)=120≤210h(3/10)=449.728, ratio 3.748
  • (94)=126≤29h(4/9)=484.2756, ratio 3.843
  • (126)=924≤212h(6/12)=4096, ratio 4.433

Shearer's inequality

Subsets A1,…,Am⊆[n] cover every coordinate at least r times. Bound H(X) by the entropies of the views XAj.

rH(X)≤∑j=1mH(XAj).

  1. Chain rule inside each view, in the global order: H(XA)=∑i∈AH(Xi ∣ XA∩[i−1]).

    chain rule

  2. H(Xi ∣ XA∩[i−1])≥H(Xi ∣ X[i−1]).

    conditioning
  3. ∑jH(XAj)≥∑j∑i∈AjH(Xi ∣ X<i)≥r∑iH(Xi ∣ X<i)=rH(X).
    cover
Clever move.

Describe the same information through overlapping partial views.

  • |F|=7, coverage r=2
  • 2H(X)=5.615≤∑jH(XAj)=6.227 bits
  • |F|≤26.227/2=8.6537

Loomis–Whitney

A finite set of lattice points casts three shadows. How large can it be?

|S|d−1≤∏i=1d|πi(S)|,  |S|2≤|πxyS| |πxzS| |πyzS|.

  1. Each coordinate lies in exactly d−1 of the deletion projections.

    cover
  2. (d−1)H(X)≤∑iH(πiX)≤∑ilog|πi(S)|.
    Shearer + support

  3. Exponentiate: |S|d−1≤∏i|πi(S)|.

    exponentiate
Clever move.

Recognise deletion projections as a cover with multiplicity d−1.

  • staircase: |S|=10, shadows 6, 6, 6; |S|2=100≤216, |S|≤14.6969
  • box: |S|2=64=64, tight

Bregman's theorem: proof architecture

per(A)≤∏i(di!)1/di.

Random reveal ordering:

  1. choose a random combinatorial object
  2. encode it by local variables
  3. reveal variables in random order
  4. use chain rule
  5. bound each conditional entropy by log(number of options)
  6. average over reveal order
  7. exponentiate

  1. H(M)=logper(A) with M=(X1,…,Xn).

    uniform

  2. For any order: H(M)=∑iH(Xi ∣ earlier Xj).

    chain rule

  3. H(Xi ∣ earlier)≤E[logNi]: when i is revealed, only Ni neighbours are still free.

    support bound

  4. Average over a uniformly random order R.

    averaging

  5. For fixed M, Ni is uniform on {1,…,di}: it is one plus the number of i's neighbours' partners revealed after i.

    symmetry
  6. ElogNi=1di∑k=1dilogk=log(di!)di.
    averaging identity
  7. logperA≤∑ilog(di!)di; exponentiate.
    sum + exponentiate
  • Cycle C₆: per =2≤2.8284
  • Complete K₃,₃: per =6≤6 (tight)
  • Ferrers board (degrees 2, 3, 4, 4): per =8≤12.5894
  • Irregular (degrees 2, 3, 2, 3): per =4≤6.6039

Problem ladder

  1. How many bits identify one of N objects? (uniform entropy)
  2. Maximise entropy on N outcomes (maximum entropy)
  3. Bound a family by coordinate supports (subadditivity)
  4. Bound C(n,k) (binary entropy)
  5. Bound multinomial coefficients (subadditivity)
  6. Count constrained binary strings (conditional entropy)
  7. Bound a set family from marginals (indicator encoding)
  8. Projection bound in 3D (Shearer)
  9. Loomis–Whitney (Shearer)
  10. Optimise a fractional cover (fractional Shearer)
  11. Bound perfect matchings (chain rule)
  12. Bregman's theorem (random reveal ordering)
  13. Typical binary strings (typical sets)
  14. Method of types (entropy asymptotics)
  15. Hypergraph projection problem (fractional covers)
  16. Sumset toy problem (entropy under maps)

The master workflow

  1. COUNT
  2. RANDOMIZE
  3. ENCODE
  4. DECOMPOSE INFORMATION
  5. THROW AWAY ONLY THE DEPENDENCE YOU CAN AFFORD
  6. BOUND LOCAL UNCERTAINTY
  7. ADD INFORMATION COSTS
  8. EXPONENTIATE

The three reusable moves: chain rule (reveal an object progressively), Shearer (bound an object through overlapping partial views) and random reveal order (make local conditional uncertainty average to something tractable).
