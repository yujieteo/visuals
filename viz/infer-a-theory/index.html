Infer a Theory

From observations to effective actions and renormalisation

Describe a fluctuating quantity in plain English, and this page turns the observations into a probabilistic effective theory: explicit statistical claims, an effective action with uncertain coupling constants, a Wilsonian renormalisation-group flow across scales, predictions, and the next measurement worth making. The interactive inference needs JavaScript; the ideas and the worked example are below.

Probability ↔ action

p[φ] = e^(−S[φ]) / Z   ⇔   S[φ] = −log p[φ] + constant

A probability model of a process φ(t) is the same thing as an action S: the action is minus the log-probability, and the normalisation is the partition function Z.

Observation → operator → coupling

A statement such as “bad intervals tend to be followed by bad intervals” constrains an observable (the lag-1 correlation). Maximum entropy turns constraints ⟨Oᵢ⟩ = cᵢ into the least committal distribution p ∝ exp(−Σ gᵢOᵢ): each observable becomes an operator Oᵢ, and its Lagrange multiplier gᵢ is the coupling constant. Uncertain observations give a probability distribution over couplings rather than one value.

Wilsonian coarse-graining

Averaging neighbouring values in pairs, Φⱼ = (φ₂ⱼ + φ₂ⱼ₊₁)/2, and asking which effective action describes the averages, gives a flow of couplings with scale. Features that shrink under this flow (irrelevant directions) stop mattering at large scales; features that grow (relevant directions) dominate. For a binary field the same idea is literal decimation: keep every other value and sum over the rest.

Inverse RG is not unique

Coarse-graining loses information, so it cannot be run backwards. Instead, candidate finer-scale theories are run forward and kept when they reproduce what was observed. Many microscopic theories survive, and their spread grows toward finer scales until the observations no longer constrain them at all.

Worked example: live football stream bandwidth

  1. At 10-second resolution, bandwidth usually changes gradually.
  2. It is very likely that a poor 10-second interval is followed by another poor interval.
  3. Large downward deviations occur more often than a Gaussian model predicts.
  4. At one-minute resolution, the distribution looks approximately Gaussian.

With JavaScript these become claims about lag-1 correlation, a lower-tail ratio and Gaussianity at 60 s; an effective action S = g₂Σφ² + k₁Σ(φₜ₊₁ − φₜ)² + g_tail Σ V_tail(φ); a forward flow toward the Gaussian family; a widening family of compatible finer-scale theories; and a recommended next observation. This is an illustrative inference, not an empirical statement about networks.
