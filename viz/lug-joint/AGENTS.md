# Lug and pin joint calculator

`index.html` is generated by `build.py` from `template.html`, `engine.js` (the pure calculation core, `LugJoint`, with `REFERENCE_CASES`, the self-tests and the joint's beamdswitch report; no DOM access) and `raw.json`; never edit or hand-merge it.

Values are stored in N, mm and MPa whatever units are displayed. A new reference case goes in `REFERENCE_CASES` in `engine.js`; it then runs in the page's self-tests and both test suites.

Its tests are in `tests/`; `python3 ../../scripts/check.py lug-joint` runs its checks. Rules for every visual: [SKILLS.md](../../SKILLS.md).
