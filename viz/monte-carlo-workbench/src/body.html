    Model text: one line for each part
    • title: … and problem: …
    • param name = 0.5 {unit} "note": a parameter
    • X ~ poisson(lambda = rate) repeat 10 {unit}: a random variable, with an optional number of i.i.d. copies
    • Y := max(X - c, 0): a definition
    • prob name = X > 3, mean name = Y, ratio name = E[A] / E[B]: quantities
    • alt "Label": c = 4; rate = 2: a decision alternative
    • minimise name or maximise name, and require name <= 0.05
    • focus X: the focus variable, which the distribution plot shows
    • censoring: right T by C: the censoring mechanism of the observation
    • initial: … and dynamics: …: the initial conditions and the dynamics of a model with a process, in words
    • N ~ poisson(lambda = 3, u = U[1]): a scalar law drawn by the inverse transform of a given uniform, such as a copula component
    • control C = X: the control variate of the control-variate method, an affine function of variables with known means
    • law Sev(a) pdf(x) = a*x^(-a - 1) on [1, inf] where a > 1 obs [1.3, 2.2] grid 4096: a custom law, then X ~ Sev(a = 2.5)

    Constructed laws: mixture_F(w, …), compound_F(freq, …) and truncated_F(…, lower, upper) for a law F of this page, such as mixture_poisson(w = [0.7, 0.3], lambda = [2, 9]) or truncated_mixture_geometric(w, p, lower, upper). Also empirical(x, w) and kde(x, w, h). In a mixture, each parameter of F is a vector with one entry for each component, or one number for all.

    Custom laws: law NAME(parameters) KIND(argument) = expression with the kinds pdf, logpdf, density, pmf, table, cdf, quantile, mgf, cf, and the clauses on [lo, hi], where condition, obs [values], probs [probabilities] (a table) and grid N. In a CF, i is the imaginary unit. The arguments of a custom law read parameters only.

    Discrete laws: bernoulli(p), binomial(n, p), categorical(p), multinomial(n, p), uniform(a, b), geometric(p), negbin(r, p), poisson(lambda), hypergeometric(N, K, n), zipf(s, N).

    Continuous laws: cuniform(a, b), normal(mu, sigma), mvnormal(mu, cov), exponential(rate), gamma(k, theta), erlang(k, rate), beta(a, b), dirichlet(alpha), chisq(nu), student(nu), fisher(d1, d2), logistic(mu, s), laplace(mu, b). A vector law gives a vector: use X[1], sum(X) or sum(w*X).

    Positive, heavy-tailed and extreme-value laws: lognormal(mu, sigma), weibull(k, lambda), invgauss(mu, lambda), gompertz(eta, b), loglogistic(alpha, beta), pareto1(xm, alpha), pareto2(mu, sigma, alpha), burr12(c, k, lambda), frechet(alpha, s, m), cauchy(x0, gamma), levy(mu, c), stable(alpha, beta, gamma, delta), gev(xi, mu, sigma), gpd(xi, sigma, mu), gumbel(mu, beta), revweibull(alpha, mu, sigma). The stable law uses Nolan's S0 parameterisation.

    Copulas (a vector of d uniforms): gaussiancopula(rho, d), tcopula(rho, nu, d), claytoncopula(theta, d), gumbelcopula(theta, d), frankcopula(theta, d). One rho holds for every pair; a vector gives the d(d − 1)/2 correlations above the diagonal, row by row.

    Processes (a path of steps + 1 values at the grid times; X[1] is the value at t = 0): brownian(x0, mu, sigma, T, steps), gbm(s0, mu, sigma, T, steps), ou(x0, kappa, theta, sigma, T, steps), poissonprocess(lambda, amp, period, T, steps), compoundprocess(x0, drift, lambda, jump, T, steps), markovchain(P, x0, steps), branching(z0, m, k, steps), hawkes(mu, alpha, beta, T, steps), variancegamma(x0, theta, sigma, nu, T, steps). The diffusions also take coarsen, and a model with the parameters steps and coarsen runs on multilevel grids.

    Censoring: censoring: right T by C observes T_obs = min(T, C) and T_event = 1 when T ≤ C. The line censoring: left T by C observes max(T, C) and 1 when T ≥ C.

    Functions: abs, sqrt, exp, log, log1p, floor, ceil, round, pow, min, max, pmin, pmax, if, sum, mean, prod, len, count, distinct, maxcount, any, all, normalize, median, quantile(x, p), hill(x, k), km(times, events, t), sin, cos, tan, atan, lgamma, first, last, cumsum. The parser accepts no other name, so an expression cannot run code.

                Multilevel Monte Carlo

                Level l runs the fine grid of n0 · 2^l steps and the coarse grid of half as many on the same Brownian increments, so the correction Y_l = P_l − P_(l−1) has a small variance. The sum of the level means estimates the value on the finest grid. The page keeps its Monte Carlo error apart from the discretisation bias of that grid.

                Generator and limits
                

                The generator is Philox4x32-10 (Salmon, Moraes, Dror and Shaw, 2011). The tests check it against the known-answer vectors of Random123. Each stream comes from the seed, the stream name, the replicate and the variable, so the result does not depend on the number of workers.
