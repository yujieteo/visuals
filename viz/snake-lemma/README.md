# Snake Lemma: an interactive diagram chase

Discover the Snake Lemma by following one element through a commutative diagram
with exact rows. The element is a token on a rigid diagram; every move is one of a
small vocabulary (apply a map, choose a lift marked as a CHOICE, an exactness step,
kernel inference, a commutativity rewrite, a quotient), and the hypothesis that pays
for each backwards move is highlighted. The guided proof constructs
δ : ker γ → coker α and draws the snake only once the chase has been made; a
"try another lift" experiment with a Raw A / Mod out by im α toggle shows the
choices collapsing in coker α. The derived six-term sequence has clickable
junctions that open exactness chases at ker β, ker γ (correcting a lift), coker α
and coker β. The ℤ example (α = 2, γ = 0, β(a, c) = (2a + c, 0), δ(n) = n mod 2)
has a lift slider. The Chase Lab offers only the moves the mathematics allows,
and each fact keeps its justification. Break assumptions, a live proof trace,
synchronised diagram, algebra and sequence views, a ⌘K / Ctrl+K palette,
presentation mode and stable hash URLs run on the same state machine. Export
writes a beamdswitch deck.

`index.html` is one self-contained page with no dependencies, no network requests
(a Content-Security-Policy forbids them) and no runtime build step; it works from
`file://`, offline and inside an iframe, and without JavaScript it is a readable
document of the diagram, the sequence, the six-step construction of δ, the
well-definedness argument and the ℤ example.

## Export

Export → Beam MD Switch offers Short (about 8 slides), Standard (about 20, the
default) and Full proof presets, plus "This chase" from the Chase Lab; Copy
Markdown, Download .md and Copy deck sequence. Decks follow the site's standard
report template (Set-up, Method, Results, Checks and takeaway; narration on every
slide; voice `bf_emma`). Each `. . .` reveal is one state of the page, in the order
the page shows it, tagged with its stable state id as a CommonMark comment line:

```markdown
[//]: # "beam-md-switch visual=snake-lemma state=proof/lift switch=1"
```

beamdswitch escapes raw HTML, so an HTML comment would print on the slide; an
unused link definition is dropped by beamdswitch and by every CommonMark
renderer. Slides are frames (`##`), not `---` separators, because that is what
beamdswitch parses. The Standard deck puts Chase Lab before "The proof as a
diagram chase" so that the `:::` key frame ends the deck.

## State URLs

`#proof/start` … `#proof/sequence`, `#exact/ker-gamma?step=3`,
`#example/integer?k=2&c=1`, `#proof/well-defined?view=mod&lifts=3`,
`#lab?start=c&ops=lift.pp,apply.beta`, any of them with
`&off=p-prime-surjective,…` for Break mode. Back and Forward restore the state.

## Tests

`tests/snake-lemma.test.mjs` (Node's built-in runner) checks the ℤ example's
squares, δ(n) = n mod 2 and that every permitted lift gives the same coset; the
six-term sequence of the example; the dependency graph and where Break mode stops;
the Chase Lab's move generation and the exactness chases it can run; URL
round-trips; that every preset and an exported lab chase parse with beamdswitch's
own parser, keep the reveal order and are deterministic; the challenge language;
that the page is built from its sources; and, booting the page against a stand-in
DOM, the WebMCP tools and the export buttons. Run them from the repository root
with `node --test 'tests/*.test.{mjs,cjs}'`. They live in
[yujieteo/snake-lemma](https://github.com/yujieteo/snake-lemma) with read-only copies of
beamdswitch's deck parser and the site's shared template in `tests/fixtures/beamdswitch/`,
and its CI runs them; the site's `visuals/snake-lemma/` is a port of the page files
and carries no tests.
