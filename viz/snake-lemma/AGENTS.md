# AGENTS.md: Snake Lemma diagram chase

An interactive proof of the Snake Lemma: one element is chased through a commutative diagram with exact rows using a small vocabulary of legal moves, the guided proof constructs δ : ker γ → coker α, and the lab exports a narrated beamdswitch deck. Live at <https://teoyujie.org/visuals/snake-lemma/>.

## Source of truth

The standalone repository [yujieteo/snake-lemma](https://github.com/yujieteo/snake-lemma) is where this visualisation and its tests develop and where its CI runs them; it is the source of truth. `visuals/snake-lemma/` in [yujieteo/site](https://github.com/yujieteo/site/tree/main/visuals/snake-lemma) is a port of the page files, refreshed whenever the lab is updated, and the site runs no logic tests for it. Porting copies the folder minus `tests/` and `.github/`. AGENTS.md and SKILLS.md therefore must not link into either (the site checks that their links resolve).

## Files and data

See [README.md](README.md). `index.html` is generated by [build.mjs](build.mjs) from `src/`: never edit it by hand. `<script id="snake-lemma-engine">` is `src/engine.js`, the pure mathematical core (`self.SnakeLemma`, also `require`-able; no DOM, storage, clock, randomness or network); `<script id="beamdswitch">` is `beamdswitch.js`; `<script id="snake-lemma-ui">` is `src/ui.js`, the page and the WebMCP tools. `raw.json` (published as `data.json`) is the engine's `catalogue()` and is generated too.

The tests are in `tests/`, with read-only copies of beamdswitch's deck parsers and the site's shared template (`templates/beamdswitch.js` and `templates/beamdswitch-report.md`) in `tests/fixtures/beamdswitch/`.

## Build, test and verify

From the repository root:

```sh
node build.mjs            # rewrite index.html and raw.json from src/
node build.mjs --check    # exit 1 if either is stale
node --test 'tests/*.test.{mjs,cjs}'
```

CI (`.github/workflows/ci.yml`) runs `node build.mjs --check` and the tests on every push and pull request: `tests/snake-lemma.test.mjs` checks the ℤ example, the six-term sequence, the dependency graph and Break mode, the Chase Lab, URL round-trips, every beamdswitch preset and lab export, the page build and, booting the page against a stand-in DOM, the WebMCP tools and export buttons. In yujieteo/site the only Snake Lemma checks are the site's integration tests: the published copy, the catalogue stub and the folder docs. When the site's `templates/beamdswitch.js` changes, copy it to both `beamdswitch.js` and `tests/fixtures/beamdswitch/template.js` and rebuild.

## Conventions

- `index.html` is one self-contained HTML file with no dependencies and no network access (a Content-Security-Policy forbids it); it works from `file://`, offline, in an iframe and, as a readable document, without JavaScript.
- The engine is deterministic: no clock, randomness or storage, so decks and state URLs are reproducible.
- Tests use Node's built-in `node --test` runner only; never add Vitest, Jest or a `package.json`.
- The beamdswitch deck is written with the unchanged shared template (`beamdswitch.js`, a copy of the site's `templates/beamdswitch.js`) and declares `voice: bf_emma` in its front matter.
