# AGENTS.md

The computing salary premium widened: Graduate Employment Survey degrees' gross monthly medians relative to each year's median: computing-titled degrees moved from 0.6% below it in 2013 to 36.4% above it in 2024.

Live: https://teoyujie.org/visuals/graduate-employment-survey/

## Source of truth

The standalone repository [yujieteo/graduate-employment-survey](https://github.com/yujieteo/graduate-employment-survey) is where this visualisation and its tests develop and where CI runs them. `viz/graduate-employment-survey/` in [yujieteo/visuals](https://github.com/yujieteo/visuals) is a port of its page files (with its data files in `data/graduate-employment-survey/`), refreshed when the visualisation is updated, and neither yujieteo/visuals nor yujieteo/site (which publishes it at <https://teoyujie.org/visuals/graduate-employment-survey/>) runs logic tests for it. Porting copies the repository minus `tests/` and `.github/`: the page files into `viz/graduate-employment-survey/` and the data files into `data/graduate-employment-survey/`.

## Files

| File | Role |
| --- | --- |
| `index.html` | Generated page. Do not hand-edit. |
| `beamdswitch.js` | Unchanged copy of the site's beamdswitch report template, inlined into `index.html`. |
| `report.js` | Builds the narrated deck from the page's data, inlined into `index.html`. |
| `AGENTS.md`, `SKILLS.md`, `LICENSE` | Agent guides and the MIT licence. |

## Build, test and verify

Run from the root of a yujieteo/graduate-employment-survey checkout (Node 22; nothing to install):

```sh
node --test 'tests/*.test.mjs'
```

`index.html` is generated by `scripts/build_ges.py` in yujieteo/visuals, whose paths assume that repository's layout (`viz/graduate-employment-survey/` for the page files, `data/graduate-employment-survey/` for the data files); regenerate it there (`--verify` checks the committed page) and copy the result back here. Never hand-edit `index.html`. Before opening a pull request, run the whole suite, as CI (`.github/workflows/ci.yml`) does on every push and pull request.

## Data and tests

- Data: `raw.csv` and `meta.json`.
- Deck report: `report.js` in this folder.
- Tests: `tests/graduate-employment-survey-beamdswitch.test.mjs`, and `tests/voice-beamdswitch.test.mjs` for the deck's narration voice.

## Conventions

- Single self-contained HTML page: CSS, data and JavaScript are inline, with no external requests.
- JavaScript tests run with `node --test` only; never add Vitest or another runner.
- Exported beamdswitch decks declare `voice: bf_emma` (the default in `beamdswitch.js`).
- WebMCP tools are read-only (`annotations: {readOnlyHint: true}`) and the page works without `modelContext`.
- Never commit credentials, host details or absolute home-directory paths.
