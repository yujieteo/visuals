Pigeonhole → Averages

Global totals force local extremes

One argument at three levels

The page is interactive with JavaScript on. Without it, here is the whole chain and its proofs.

1. Pigeonhole principle

If N > k objects go into k boxes, some box holds at least two. Proof: with at most 1 per box, k boxes hold at most k objects, so N ≤ k would be required. With 5 pigeons and 4 holes, 5 ≤ 4 is false.

2. Generalised pigeonhole principle

Put N objects into k boxes with occupancies n1 + ⋯ + nk = N. Then max ni ≥ ⌈N/k⌉ and min ni ≤ ⌊N/k⌋.

Proof: if every ni < N/k, adding gives Σni < k · N/k = N, but Σni = N. So some ni ≥ N/k, and since it is a whole number, ni ≥ ⌈N/k⌉. Reversing every inequality gives the minimum.

Example: 23 objects in 5 boxes. 23/5 = 4.6, so some box holds at least 5: if every box held at most 4, the total would be at most 5 · 4 = 20 < 23. The most balanced configuration is 5, 5, 5, 4, 4.

3. Principle of averages

For real numbers x1, …, xn with average x̄ = (x1 + ⋯ + xn)/n: min xi ≤ x̄ ≤ max xi. Some value is at least the average and some value is at most it.

Proof: if every xi < x̄, then Σxi < nx̄ = Σxi, which is impossible; likewise if every xi > x̄. Equivalently, the deviations di = xi − x̄ sum to 0, so a positive deviation forces a negative one. Equality holds exactly when all values are equal; otherwise min xi < x̄ < max xi.

Example: 2.2, 3.7, 5.1, 8.4, 0.6 have average 20/5 = 4, and 0.6 ≤ 4 ≤ 8.4.

Why this is pigeonhole

N objects in k boxes → occupancies summing to N → average occupancy N/k → some ni ≥ N/k and some nj ≤ N/k → for whole numbers, max ≥ ⌈N/k⌉ and min ≤ ⌊N/k⌋ → forget that the values are whole numbers → min xi ≤ x̄ ≤ max xi.

Things the theorems do not say

  • Pigeonhole says some box is crowded (∃i), not which one.
  • ⌈N/k⌉ is a lower bound on the maximum, not its value: 23 = 23 + 0 + 0 + 0 + 0 has maximum 23.
  • The average need not be one of the values: 1 and 2 average 1.5, and 1 < 1.5 < 2.
  • Above and below need not be equally many: 0, 0, 0, 0, 10 average 2, with four values below and one above.

Global constraints force local structure: something must be at least the average and something at most it, otherwise the total could not be n times the average.
