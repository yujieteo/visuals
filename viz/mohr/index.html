Mohr's Circle Visualiser

Transform a 3D stress or small-strain state: principal values and directions, the three Mohr circles and the region between them, and the 2D circle of a rotation about any axis. Drag the angle handle to turn the plane and watch the element, the cut plane and the failure checks follow.

A teaching tool and calculator for isotropic linear-elastic, small-strain states. Check results independently before relying on them.

    Hand calculations

    The current state worked by hand for the 2D view's axis: the in-plane components, the circle's centre and radius, the in-plane principal values and angle, the maximum in-plane shear, the element rotated by θ (or the plane given by direction cosines), then the 3D principal values and the absolute maximum shear. Each line is the formula, the numbers substituted, then the result; every result is this page's own value, in its units, sign convention and digits.

    Import and export

    JSON holds the full state as displayed (units and sign convention recorded); the Markdown report embeds the same JSON, which is all an import reads.

    The beamdswitch button saves this state as a narrated talk: a Markdown deck with the set-up, method, results with the hand calculations, and checks, every number as shown here, and a spoken narration on every slide. Open it in beamdswitch to get slides, a handout, narration and a video. Copy deck puts the same deck on the clipboard to paste into beamdswitch, for when the browser blocks the download.

    Self-test

    Runs on every load against presets 1–8, rotation and Hooke round trips, the shear-convention geometry, rosette formulas, unit conversions and export round trips.

      Conventions: stress is stored in MPa, tension positive; strain as small strain with tensor shear εxy = γxy/2. Compression positive negates the whole displayed tensor. Shear convention A plots tensor-positive τ downward so the point turns the same way as the element; B plots it upward. Everything runs in this page; nothing is fetched.
