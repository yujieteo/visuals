# AGENTS.md

What did 2020 Singapore analyses say?: Four dated 2020 Singapore COVID-19 analyses paired with later public records; one is a direct conditional forecast outcome, the others show policy overlap, a related event, or a consistent trend.

Live: https://teoyujie.org/visuals/singapore-covid-governance-hindsight/

## Source of truth

The standalone repository [yujieteo/sg-covid-hindsight](https://github.com/yujieteo/sg-covid-hindsight) is where this visualisation and its tests develop and where CI runs them. `viz/singapore-covid-governance-hindsight/` in [yujieteo/visuals](https://github.com/yujieteo/visuals) is a byte-for-byte port of its page files, with its data files in `data/singapore-covid-governance-hindsight/`. yujieteo/site publishes it at <https://teoyujie.org/visuals/singapore-covid-governance-hindsight/> from the yujieteo/visuals commit pinned in its `data/visuals/singapore-covid-governance-hindsight.pin`. Neither runs this repository's tests.

## Files

| File | Role |
| --- | --- |
| `index.html` | Generated page. Do not hand-edit. |
| `beamdswitch.js` | Unchanged copy of the site's beamdswitch report template, inlined into `index.html`. |

| `AGENTS.md`, `SKILLS.md`, `LICENSE` | Agent guides and the MIT licence. |

## Build, test and verify

Run from the root of a yujieteo/sg-covid-hindsight checkout (Node 22; nothing to install):

```sh
node --test 'tests/*.test.mjs'
```

`index.html` is generated by `scripts/build_singapore_covid_governance_hindsight.py` in yujieteo/visuals, whose paths assume that repository's layout (`viz/singapore-covid-governance-hindsight/` for the page files, `data/singapore-covid-governance-hindsight/` for the data files); regenerate it there (`--verify` checks the committed page) and copy the result back here. Never hand-edit `index.html`. CI (`.github/workflows/ci.yml`) runs the suite on every push and pull request.

## Change workflow

1. Change and test here. Run the suite and check the page end to end: open `index.html` in a browser, use each control and both deck buttons, and confirm the console shows no errors. When a change adds or removes tests, time the suite before and after (`time node --test 'tests/*.test.mjs'`) and give both times in the pull request. Validate the branch with no-mistakes and get CI green.
2. Port to yujieteo/visuals: copy `index.html`, `beamdswitch.js`, `report.js`, `AGENTS.md`, `SKILLS.md` and `LICENSE` byte for byte into `viz/singapore-covid-governance-hindsight/` and `raw.csv` and `meta.json` into `data/singapore-covid-governance-hindsight/`. `README.md`, `tests/` and `.github/` stay here.
3. Publish: a yujieteo/site pull request moves `data/visuals/singapore-covid-governance-hindsight.pin` to the new yujieteo/visuals commit. It runs only the site-level tests, never this repository's.

## Data and tests

- Data: `raw.csv` and `meta.json`.
- Deck report: `report.js` in this folder.
- Tests: `tests/singapore-covid-governance-hindsight-beamdswitch.test.mjs`, and `tests/voice-beamdswitch.test.mjs` for the deck's narration voice.

## Conventions

- Single self-contained HTML page: CSS, data and JavaScript are inline, with no external requests.
- Tests run with `node --test` (JavaScript) or `unittest` (Python) only; never add Vitest, pytest or another runner.
- `beamdswitch.js` stays byte-identical to yujieteo/site `templates/beamdswitch.js`; the tests check it.
- Exported beamdswitch decks declare `voice: bf_emma` (the default in `beamdswitch.js`).
- WebMCP tools are read-only (`annotations: {readOnlyHint: true}`) and the page works without `modelContext`.
- Never commit credentials, host details or absolute home-directory paths.
