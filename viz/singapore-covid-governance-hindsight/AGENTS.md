# AGENTS.md

What did 2020 Singapore analyses say?: Four dated 2020 Singapore COVID-19 analyses paired with later public records; one is a direct conditional forecast outcome, the others show policy overlap, a related event, or a consistent trend.

Live: https://teoyujie.org/visuals/singapore-covid-governance-hindsight/

## Source of truth

The standalone repository [yujieteo/sg-covid-hindsight](https://github.com/yujieteo/sg-covid-hindsight) is where this visualisation and its tests develop and where CI runs them. `viz/singapore-covid-governance-hindsight/` in [yujieteo/visuals](https://github.com/yujieteo/visuals) is a port of its page files (with its data files in `data/singapore-covid-governance-hindsight/`), refreshed when the visualisation is updated, and neither yujieteo/visuals nor yujieteo/site (which publishes it at <https://teoyujie.org/visuals/singapore-covid-governance-hindsight/>) runs logic tests for it. Porting copies the repository minus `tests/` and `.github/`: the page files into `viz/singapore-covid-governance-hindsight/` and the data files into `data/singapore-covid-governance-hindsight/`.

## Files

| File | Role |
| --- | --- |
| `index.html` | Generated page. Do not hand-edit. |
| `beamdswitch.js` | Unchanged copy of the site's beamdswitch report template, inlined into `index.html`. |

## Build, test and verify

Run from the root of a yujieteo/sg-covid-hindsight checkout (Node 22; nothing to install):

```sh
node --test 'tests/*.test.mjs'
```

`index.html` is generated by `scripts/build_singapore_covid_governance_hindsight.py` in yujieteo/visuals, whose paths assume that repository's layout (`viz/singapore-covid-governance-hindsight/` for the page files, `data/singapore-covid-governance-hindsight/` for the data files); regenerate it there (`--verify` checks the committed page) and copy the result back here. Never hand-edit `index.html`. Before opening a pull request, run the whole suite, as CI (`.github/workflows/ci.yml`) does on every push and pull request.

## Data and tests

- Data: `raw.csv` and `meta.json`.
- Deck report: `report.js` in this folder.
- Tests: `tests/singapore-covid-governance-hindsight-beamdswitch.test.mjs`, and `tests/voice-beamdswitch.test.mjs` for the deck's narration voice.

## Conventions

- Single self-contained HTML page: CSS, data and JavaScript are inline, with no external requests.
- JavaScript tests run with `node --test` only; never add Vitest or another runner.
- Exported beamdswitch decks declare `voice: bf_emma` (the default in `beamdswitch.js`).
- WebMCP tools are read-only (`annotations: {readOnlyHint: true}`) and the page works without `modelContext`.
- Never commit credentials, host details or absolute home-directory paths.
