# What did 2020 Singapore analyses say?

`index.html` is generated by `build.py` from `raw.csv`, `meta.json`, `beamdswitch.js` and `report.js`: never hand-edit it. Change those or `build.py`, then run `python3 build.py`. `beamdswitch.js` is the site's template, unchanged; the tests check it.

Its tests are in `tests/`; `python3 ../../scripts/check.py singapore-covid-governance-hindsight` runs its checks. Rules for every visual: [SKILLS.md](../../SKILLS.md).
