# Arm cash conversion

`index.html` is generated by `build.py` from `raw.json` (SEC company facts) and `meta.json`: never hand-edit it. Change those or `build.py`, run `python3 build.py`, then check with `python3 ../../scripts/check.py arm`.

`build.py` holds only this page's words (`CASE`); the shared `scripts/stock_cases.py` and `scripts/templates/stock-cases-report.js`, listed in `uses` in `visual.json`, render it and the other stock pages.

Its logic, deck and browser tests still run in [yujieteo/arm](https://github.com/yujieteo/arm) until that repository is imported here with its history. Rules for every visual: [SKILLS.md](../../SKILLS.md).
