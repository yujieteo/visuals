Probabilistic Method Atlas

A visual laboratory for the probabilistic method. The interactive labs, proof lens, deck mode and Markdown export need JavaScript; this is the static summary.

The universal proof machine: random experiment → observable → dependency → inequality → deterministic consequence.

Worked example: the first moment and Ramsey numbers

  1. Let Ω be the 2^45 colourings of the edges of K_10, all equally likely.
  2. For each 5-set S let I_S = 1 exactly when all 10 edges inside S share a colour.
  3. Set X = Σ_S I_S, the number of monochromatic k-sets.
  4. By linearity, E[X] = C(10,5) · 2^(1−10) = 0.4922.
  5. E[X] = 0.4922 < 1 and X is a nonnegative integer, so Pr[X = 0] > 0.
  6. Therefore some colouring of K_10 has no monochromatic K_5, and R(5,5) > 10.

With n = 10 and k = 5: E[X] = 0.4922 < 1, so some red/blue colouring of K10 has no monochromatic K5. A simulation could only illustrate this; the inequality proves it.

Labs in this release

  • Basic method and first moment — If the expected number of failures is below one, some outcome has no failure at all.
  • Linearity of expectation — The expectation of a sum is the sum of expectations, however tangled the summands are.
  • Alterations — Build something slightly wrong at random, then repair it; the repair costs less than it gains.
  • Second moment method — A large mean is not enough: the variance must be small compared with the mean squared.
  • Lovász Local Lemma — Many bad events are harmless if each one interacts with only a few others.
  • Moser–Tardos resampling — Fix one violated constraint at a time by resampling only its variables; under the Local Lemma condition this ends fast.
  • Janson inequality and the Poisson paradigm — Rare, mostly independent events behave like a Poisson count; Janson pays for the overlaps exactly.
  • Chernoff bounds — A sum of many independent small pieces almost never strays far from its mean: the tail falls exponentially.
  • Martingales and bounded differences — Reveal the random graph one edge at a time; our running prediction of the statistic can only move a little each step.
  • Rödl nibble — Many gentle random choices, each followed by a clean-up, beat one giant random choice.
  • Quasirandomness and expander mixing — A deterministic graph can stand in for a random one if it passes the few statistics a proof actually uses.
  • Random graph phase transition — Exploring a vertex's component looks like a branching process; average offspring c = np decides between small and giant.
  • Dependent random choice — Choose a few random vertices and keep their common neighbourhood: sets with few common neighbours are unlikely to survive together.
  • Discrepancy — Random ±1 signs balance every set to within about √(n log m); no set can be badly unbalanced with much probability.
  • ε-nets and VC dimension — A modest random sample hits every heavy range at once, because a family of bounded VC dimension has few distinct ranges.
  • Entropy and counting — To count a family, pick a uniform member at random: its entropy is log of the count, and entropy splits over coordinates.
  • Conditional expectation (derandomisation) — Fix the random bits one by one, always keeping the conditional expectation from falling; when no randomness is left, the object is at least as good as the average.
  • Property testing — A graph far from triangle-free has triangles everywhere, so a tiny random sample sees one.
