# Visual skeleton: the generator's example

Generated by `scripts/new_visual.py` (see `generated.json`). The domain is yours: `src/model.js` (state fields, examples, derive), `src/view.js` (render, controls, WebMCP tools), `src/body.html`, `src/style.css`, `report.js`, `raw.json`, `tests/visual-skeleton-model.test.mjs` and `e2e/`. Edit them, then run `python3 build.py`; never hand-edit `index.html`.

The mechanical files (`build.py`, `beamdswitch.js`, `tsconfig.json`, `types/globals.d.ts`, `tests/visual-skeleton-kit.test.mjs`) come from the generator: `python3 ../../scripts/new_visual.py --check visual-skeleton` reports drift and `--update visual-skeleton` rewrites them. `python3 ../../scripts/check.py visual-skeleton` runs every check. Rules for every visual: [SKILLS.md](../../SKILLS.md).
