# How English Grammar Works

`index.html` is generated by `build.py` from `raw.json`, `concepts.json`, `examples.json`, `meta.json` and `src/`: never hand-edit it. Change those or `build.py`, run `python3 build.py`, then check with `python3 ../../scripts/check.py english-grammar`.

The page must stay under the builder's 1 MB size budget; `--verify` checks it.

Its logic, deck and browser tests still run in [yujieteo/english-grammar](https://github.com/yujieteo/english-grammar) until that repository is imported here with its history. Rules for every visual: [SKILLS.md](../../SKILLS.md).
