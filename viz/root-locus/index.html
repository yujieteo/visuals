Root locus design check

Type C, G and H, drag K, read the closed-loop poles against your requirements. Everything runs offline in this page; the exported Markdown is the save file.

Loop

Open loop L = K·C·G·H, negative feedback. Closed loop T = K·C·G / (1 + K·C·G·H).

Plane

C, G and H are entered in s.

Defaults to 1. Example: (s + 2) / (s + 10)

Use ** for powers and * to multiply. Also tf([1], [1, 2]), zpk([-1], [0, -2], 3), or num = […] and den = […] lines.

Defaults to 1 (unity feedback). Example: 1 / (0.1*s + 1)

Discretisation (z-plane)

Switch to the z-plane to discretise G. C and H are then entered in z.

Delay

Padé approximation: order N adds N right-half-plane zeros (and N poles) to G.

Requirements (optional)

Leave blank to skip. Strict stability is always on. The allowed region is shaded on the plot.

Ts becomes Re(s) ≤ −4/Ts. In the z-plane the region is mapped through z = exp(s·T).

Gain range

Auto picks a K max so the branches reach their asymptotes. K runs from 0 (K ≥ 0 only).

Self-tests

The section 8 verification cases, computed live by the same numeric core that Node tests load. Also at ?selftest.

Method: roots of D + K·N from the eigenvalues of the balanced companion matrix, tracked over an adaptive K grid with nearest-neighbour matching and step halving. Breakaway points solve N·D′ − N′·D = 0; crossings solve the boundary condition exactly. Nothing is stored in the browser.

Input syntax

A small Python subset, parsed by hand (never evaluated). Numbers, complex literals such as 1+2j, lists, s, z, pi, tf, zpk, + - * / **, parentheses and unary minus. ^ is read as ** with a nudge. Multiply explicitly: 2*s, (s + 1)*(s + 2).

In the z-plane, G is still entered in s and discretised; C and H use z.
