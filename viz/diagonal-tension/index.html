Diagonal Tension: Skin, Stringers and Doubler

At the same applied shear load, what changes when a doubler is added to an aluminium skin-and-stringer panel? This page meshes the panel, solves both variants with a finite-element model in your browser and compares them.

Linear elastic, pre-buckling model. It calculates diagonal principal tension and how stress redistributes. It does not calculate a post-buckling tension field, stringer bending or crippling, fastener slip or one-sided doubler bending: those need further element formulations and validation. Background: NACA, diagonal tension.

The example uses demonstration values (E = 70,000 MPa, ν = 0.33, 2,700 kg/m³). Alloy allowables are yours to supply. Variant A is skin plus stringers; variant B adds the doubler. Both use the same mesh, restraints and load.

      Method and assumptions

      How the panel is solved
      1. A structured, conforming mesh is split at every stringer and doubler edge; each node has two translations. No skin element is duplicated: inside the doubler, the element thickness is t + t_d in variant B.
      2. Quadrilateral stiffness: isotropic plane stress, D = E/(1 − ν²)[1 ν 0; ν 1 0; 0 0 (1 − ν)/2], with 2 × 2 Gauss integration. Bars: EA/L along their direction.
      3. The global sparse stiffness and force vector are assembled, the restrained degrees of freedom eliminated, and the system solved by conjugate gradient with diagonal preconditioning. Non-positive curvature, non-finite values, the iteration limit and a failed residual check stop the run; a failed solve shows no results.
      4. Recovered: displacements, reactions, bar axial forces and the stresses at every Gauss point.
      5. From σx, σy and τxy: m = (σx + σy)/2, r = hypot((σx − σy)/2, τxy), σ1 = m + r, σ2 = m − r, θ1 = ½ atan2(2τxy, σx − σy), von Mises = √(σx² − σxσy + σy² + 3τxy²). Tension is positive.
