# Convexity Action Engine

`index.html` and the CSVs `actions.csv`, `aliases.csv` and `sources.csv` are generated by `build.py` (`--verify` checks them) from `raw.json`, `engine.js`, `meta.json` and `design-tokens.json`; never edit them by hand. `author.py` writes `raw.json` from `ontology.txt`, every number an ordinal author judgement; `derive_atus.py` rederives `atus_observed.csv` from ATUS microdata (needs pandas and rdata).

`author.py`, and so `build.py`, reads `drm_table1.csv` and `evidence.json` from the sibling folder `../everyday-actions/`; the tests carry read-only copies in `tests/fixtures/everyday-actions/`.

Label every number as judgement, model or personal, as the page does; never present a judgement as a measurement.

Its tests are in `tests/`; `python3 ../../scripts/check.py convexity-action-engine` runs its checks. Rules for every visual: [SKILLS.md](../../SKILLS.md).
