Seven drills for Regulation Set M-C doubles (register six, bring four, level 50, one Mega Evolution per battle).     Rule sheet: the four moves this page teaches
    • Protect · Normal · priority +4 · 8 PP in Champions
      Blocks most moves aimed at the user for the turn. Each consecutive use of a protecting move has 1/3 the success chance of the one before (100%, 33.3%, 11.1%, 3.7%, ...); any other action resets it. Source
    • Fake Out · Normal · priority +3 · 12 PP in Champions
      Priority +3; the target flinches. Works only on the user's first turn on the field (the Champions mod even greys it out afterwards). Normal-type, so Ghost types are immune. Blocked by Protect, Quick Guard and a Ghost target, and a flinched Pokémon loses that turn's move. Source
    • Quick Guard · Fighting · priority +3 · 16 PP in Champions
      Protects the user and its ally from moves with priority above 0 for the turn (Fake Out, Sucker Punch, ...). Priority +3 itself, so it ties Fake Out and the faster Pokémon acts first. Source
    • Parting Shot · Dark · priority +0 · 20 PP in Champions
      Lowers the target's Attack and Special Attack by 1, then the user switches out. Blocked by Protect; if the drops cannot be applied the user does not switch. Sound-based. Source
