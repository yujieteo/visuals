# Multi-armed Bandit: Thompson Sampling and UCB

`index.html` is generated by `build.py` from `raw.json`, `meta.json` and `src/`: never hand-edit it. Change those or `build.py`, run `python3 build.py`, then check with `python3 ../../scripts/check.py multi-armed-bandit`.

The page the site publishes is the newer one developed in yujieteo/multi-armed-bandit (with its own `build.py` and `src/`); this builder makes the older page until that repository is imported here.

Its logic, deck and browser tests still run in [yujieteo/multi-armed-bandit](https://github.com/yujieteo/multi-armed-bandit) until that repository is imported here with its history. Rules for every visual: [SKILLS.md](../../SKILLS.md).
