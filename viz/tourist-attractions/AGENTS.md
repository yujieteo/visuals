# How Singapore attractions are marketed

Its logic, deck and browser tests still run in [yujieteo/tourist-attractions](https://github.com/yujieteo/tourist-attractions) until that repository is imported here with its history. Rules for every visual: [SKILLS.md](../../SKILLS.md).
