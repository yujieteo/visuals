# AGENTS.md

Where to eat in Tampines hub: a map of the 20 best-rated places to eat across Tampines Mall, Century Square and Tampines 1, ranked by Google Maps rating among food-guide picks, with review summaries and HPB-based calorie and macro estimates for their mains.

Not published on teoyujie.org: this is an older, separate version of the site's Tampines food page, which develops in [yujieteo/tampines-food](https://github.com/yujieteo/tampines-food) and is live at <https://teoyujie.org/visuals/tampines-food/>.

## Source of truth

The standalone repository [yujieteo/tampines-food-map](https://github.com/yujieteo/tampines-food-map) is where this visualisation and its tests develop and where CI runs them. `viz/tampines-food-map/` in [yujieteo/visuals](https://github.com/yujieteo/visuals) is a port of its page files (with its data files in `data/tampines-food-map/`), refreshed when the visualisation is updated, and yujieteo/visuals runs no logic tests for it. Porting copies the repository minus `tests/` and `.github/`: the page files into `viz/tampines-food-map/` and the data files into `data/tampines-food-map/`.

## Build, test and verify

Run from the root of a yujieteo/tampines-food-map checkout (Node 22; nothing to install):

```sh
node --test 'tests/*.test.{mjs,cjs}'
```

`index.html` and `meta.json` are generated by `scripts/build_tampines_food_map.py` in yujieteo/visuals, whose paths assume that repository's layout (`viz/tampines-food-map/` for the page files, `data/tampines-food-map/` for the data files); regenerate them there (`--verify` checks the committed page) and copy the result back here. Never hand-edit `index.html`. Before opening a pull request, run the whole suite, as CI (`.github/workflows/ci.yml`) does on every push and pull request.

## Change workflow

Change and test this repository first, end to end (open `index.html` in a browser, filter by mall and open a place's details on the map), and run no-mistakes here. Then port the page files into `viz/tampines-food-map/` and the data files into `data/tampines-food-map/` of yujieteo/visuals. Logic tests stay here; never add them to yujieteo/visuals.

## Data and tests

- Data: `raw.json` (guide-featured places, Google Maps ratings, guide quotes, review summaries and dishes mapped to HPB SGFoodID items), `sgfoodid.json` (unchanged HPB SGFoodID food-detail responses), `osm.json` (unchanged OpenStreetMap Overpass response for the hub) and `meta.json`.
- Tests: `tests/tampines-food-map.test.mjs` checks the page's ranking, calorie and macro estimates and metadata against the data, the single-file rules, and the three WebMCP tools.

## Conventions

- Single self-contained HTML page: CSS, data and JavaScript are inline, with no external requests.
- JavaScript tests run with `node --test` only; never add Vitest or another runner.
- WebMCP tools are read-only (`annotations: {readOnlyHint: true}`) and the page works without `modelContext`.
- Never commit credentials, host details or absolute home-directory paths.
