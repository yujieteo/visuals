# AGENTS.md

What Manchester City's charges and accounts do and do not show: an evidence-first timeline that separates the Premier League allegations, the distinct 2020 CAS UEFA case, and Manchester City's latest filed accounts.

Live: https://teoyujie.org/visuals/manchester-city-finances/

## Source of truth

The standalone repository [yujieteo/manchester-city-finances](https://github.com/yujieteo/manchester-city-finances) is where this visualisation and its tests develop and where CI runs them. `viz/manchester-city-finances/` in [yujieteo/visuals](https://github.com/yujieteo/visuals) is a port of its page files (with its data files in `data/manchester-city-finances/`), refreshed when the visualisation is updated, and neither yujieteo/visuals nor yujieteo/site (which publishes it at <https://teoyujie.org/visuals/manchester-city-finances/>) runs logic tests for it. Porting copies the repository minus `tests/` and `.github/`: the page files into `viz/manchester-city-finances/` and the data files into `data/manchester-city-finances/`.

## Files

| File | Role |
| --- | --- |
| `index.html` | Generated page. Do not hand-edit. |
| `beamdswitch.js` | Unchanged copy of the site's beamdswitch report template, inlined into `index.html`. |

| `AGENTS.md`, `SKILLS.md`, `LICENSE` | Agent guides and the MIT licence. |

## Build, test and verify

Run from the root of a yujieteo/manchester-city-finances checkout (Node 22; nothing to install):

```sh
node --test 'tests/*.test.mjs'
```

`index.html` is generated by `scripts/build_manchester_city_finances.py` in yujieteo/visuals, whose paths assume that repository's layout (`viz/manchester-city-finances/` for the page files, `data/manchester-city-finances/` for the data files); regenerate it there (`--verify` checks the committed page) and copy the result back here. Never hand-edit `index.html`. Before opening a pull request, run the whole suite, as CI (`.github/workflows/ci.yml`) does on every push and pull request.

## Data and tests

- Data: `raw.csv` and `meta.json`.
- Deck report: `report.js` in this folder.
- Tests: `tests/manchester-city-finances-beamdswitch.test.mjs`, and `tests/voice-beamdswitch.test.mjs` for the deck's narration voice.

## Conventions

- Single self-contained HTML page: CSS, data and JavaScript are inline, with no external requests.
- JavaScript tests run with `node --test` only; never add Vitest or another runner.
- Exported beamdswitch decks declare `voice: bf_emma` (the default in `beamdswitch.js`).
- WebMCP tools are read-only (`annotations: {readOnlyHint: true}`) and the page works without `modelContext`.
- Never commit credentials, host details or absolute home-directory paths.
