# Sectionlab

`index.html` is generated by `build.py` from `template.html`, `raw.json`, `reference/torsion-accuracy.json`, the engine modules in `src/` and `beamdswitch.js` (the site's template, unchanged): never hand-edit it. [SKILLS.md](SKILLS.md) routes each task to its playbook and [docs/architecture.md](docs/architecture.md) explains the modules.

Units are mm, MPa, N and N·mm; never add unit conversions inside the engine. The page keeps its "verify independently" notice and is never described as design-code compliant. A torsion constant is shown only where `reference/torsion-accuracy.json` has measured its formula.

The Python references need numpy, scipy and PyYAML (`requirements-test.txt`); the check installs them into a throwaway virtual environment, and the slowest test, the torsion accuracy table, takes over a minute. `tests/browser.test.mjs` drives the built page in headless Chrome (`CHROME_PATH`, or the usual install paths): it is skipped without one locally and required under CI.

Its tests are in `tests/`; `python3 ../../scripts/check.py sectionlab` runs its checks. Rules for every visual: [SKILLS.md](../../SKILLS.md).
