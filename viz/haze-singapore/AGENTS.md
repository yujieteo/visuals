# Singapore haze, region by region

`index.html` is generated by `build.py` from `raw.json`, `boundary.geojson` and `meta.json`: never hand-edit it. Change those or `build.py`, run `python3 build.py`, then check with `python3 ../../scripts/check.py haze-singapore`.

Refresh the data with `python3 refresh.py` (data.gov.sg, no key needed): it writes `raw.json` and `visual.json`'s `fetched`, then runs the builder, which also rewrites `meta.json`. `--dry-run` prints what would change and writes nothing.

Its tests are in `tests/`, imported with their history from yujieteo/haze-singapore (now deleted) into yujieteo/visuals. Rules for every visual: [SKILLS.md](../../SKILLS.md).
