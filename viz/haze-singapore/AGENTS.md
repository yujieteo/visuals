# AGENTS.md

Singapore haze, region by region: Hourly 24-hour PSI and PM2.5 for Singapore's five NEA regions from 1 April to 29 September 2026: no PSI above 100 until 4 September, then 15 Unhealthy days and a peak of 155 in Central.

Live: https://teoyujie.org/visuals/haze-singapore/

## Source of truth

The standalone repository [yujieteo/haze-singapore](https://github.com/yujieteo/haze-singapore) is where this visualisation and its tests develop and where CI runs them. `viz/haze-singapore/` in [yujieteo/visuals](https://github.com/yujieteo/visuals) is a port of its page files (with its data files in `data/haze-singapore/`), refreshed when the visualisation is updated, and neither yujieteo/visuals nor yujieteo/site (which publishes it at <https://teoyujie.org/visuals/haze-singapore/>) runs logic tests for it. Porting copies the repository minus `tests/` and `.github/`: the page files into `viz/haze-singapore/` and the data files into `data/haze-singapore/`.

## Files

| File | Role |
| --- | --- |
| `index.html` | Generated page. Do not hand-edit. |
| `beamdswitch.js` | Unchanged copy of the site's beamdswitch report template, inlined into `index.html`. |
| `report.js` | Builds the narrated deck from the page's data, inlined into `index.html`. |
| `AGENTS.md`, `SKILLS.md`, `LICENSE` | Agent guides and the MIT licence. |

## Build, test and verify

Run from the root of a yujieteo/haze-singapore checkout (Node 22; nothing to install):

```sh
node --test 'tests/*.test.mjs'
```

`index.html` is generated by `scripts/build_haze_singapore.py` in yujieteo/visuals, whose paths assume that repository's layout (`viz/haze-singapore/` for the page files, `data/haze-singapore/` for the data files); regenerate it there (`--verify` checks the committed page) and copy the result back here. Never hand-edit `index.html`. Before opening a pull request, run the whole suite, as CI (`.github/workflows/ci.yml`) does on every push and pull request.

## Data and tests

- Data: `raw.json`, `boundary.geojson` and `meta.json`.
- Deck report: `report.js` in this folder.
- Tests: `tests/haze-singapore-beamdswitch.test.mjs`, and `tests/voice-beamdswitch.test.mjs` for the deck's narration voice.

## Conventions

- Single self-contained HTML page: CSS, data and JavaScript are inline, with no external requests.
- JavaScript tests run with `node --test` only; never add Vitest or another runner.
- Exported beamdswitch decks declare `voice: bf_emma` (the default in `beamdswitch.js`).
- WebMCP tools are read-only (`annotations: {readOnlyHint: true}`) and the page works without `modelContext`.
- Never commit credentials, host details or absolute home-directory paths.
