# Singapore haze, region by region

`index.html` is generated by `build.py` from `raw.json`, `boundary.geojson` and `meta.json`: never hand-edit it. Change those or `build.py`, run `python3 build.py`, then check with `python3 ../../scripts/check.py haze-singapore`.

Refresh the data first with `python3 fetch.py` (data.gov.sg, no key needed); the builder also rewrites `meta.json`.

Its logic, deck and browser tests still run in [yujieteo/haze-singapore](https://github.com/yujieteo/haze-singapore) until that repository is imported here with its history. Rules for every visual: [SKILLS.md](../../SKILLS.md).
